# Пустошь

Survivor-like про выжившего у убежища. Сейчас реализованы **этапы 0–6: каркас, играбельный забег, каталог контента, аккаунты, профиль и мета-прогрессия, pixel-art и звук, контент MVP**. Этап 8 (деплой) — конфигурация и страницы готовы, ждёт сервера и домена ([инструкция](docs/DEPLOY.md)). Этап 7 (Android) — код готов, сборка и проверка на телефоне отложены в самый конец. [Полный план](docs/PLAN.md).

## Требования

- Node.js 22.12+ и npm
- Python 3.12 и [uv](https://docs.astral.sh/uv/)
- PostgreSQL 16+ (локально, без Docker)

## Первый запуск

```bash
createdb wasteland
cp .env.example .env
# В .env задайте JWT_SECRET случайной строкой длиной не менее 32 символов:
# openssl rand -hex 32
make install
make migrate
make dev
```

Если PostgreSQL использует отдельного пользователя, измените `DATABASE_URL` в `.env`. URL должен начинаться с `postgresql+asyncpg://`. `make dev` запускает сервер на `http://localhost:8000` и клиент на `http://localhost:5173`. Для проверки сервера откройте `http://localhost:8000/api/v1/health`; игра доступна в браузере на порту 5173.

Для локального входа по почте оставьте `MAIL_BACKEND=console`: ссылка и код выводятся в лог сервера. Для реальной отправки задайте `MAIL_BACKEND=resend`, `RESEND_API_KEY` и `MAIL_FROM` с подтверждённым доменом. Для входа через Telegram задайте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_BOT_USERNAME`; в отдельном терминале запустите `make bot-poll`. Вебхук для развернутого сервера дополнительно требует `TELEGRAM_WEBHOOK_SECRET`.

## Команды

| Команда | Назначение |
| --- | --- |
| `make install` | Установить зависимости клиента и сервера |
| `make dev` | Запустить оба dev-сервера |
| `make bot-poll` | Запустить тестового Telegram-бота в режиме polling |
| `make migrate` | Применить миграции Alembic |
| `make test` | Запустить проверки Python, тесты и проверки клиента |
| `TEST_DATABASE_URL=postgresql+asyncpg:///wasteland_test make test` | То же, но тесты API идут на PostgreSQL после миграций Alembic (база очищается!) |
| `make content-check` | Проверить схемы JSON, реестры поведений, ссылки между файлами, наличие спрайтов/звуков и записей в `CREDITS.md` |
| `make assets` | Пересобрать спрайты, атлас, звуки и музыку (нужен `ffmpeg`) |

Числа забега лежат в `content/`: `balance.json` задаёт общие лимиты, общую сложность (`enemyHpMultiplier` и `enemyDamageMultiplier`, сейчас ×1,3 к здоровью врагов и к их урону по герою), кривую опыта и формулу награды, а каталоги `heroes/`, `weapons/`, `passives/`, `enemies/`, `pickups/`, `upgrades/` и `locations/` — игровой контент. Клиент проверяет JSON через Zod при загрузке. Для нового врага достаточно JSON в `content/enemies/` и ссылки в волне локации; для нового оружия — JSON в `content/weapons/`. Новое поведение требует класса и регистрации в `client/src/behaviors/`.

Улучшения убежища лежат в `content/upgrades/` (характеристика, `flat`/`percent`, прибавка за уровень, максимум, цена `base × growth^уровень`). Формула награды и лимиты правдоподобия — в разделе `reward` файла `balance.json`. Цены, награды и хеш контента одинаково считаются на клиенте (`client/src/economy.ts`, `client/src/content/hash.ts`) и сервере (`server/app/services/economy.py`, `content.py`); общие примеры с ожидаемыми ответами лежат в `testdata/economy_vectors.json` и проверяются тестами с обеих сторон. При изменении формулы обновите обе реализации и этот файл.

Сервер — единственный источник правды для крышек: `POST /runs/start` выдаёт `run_id` и seed, `POST /runs/{id}/finish` сам считает награду по сводке, урезает неправдоподобные значения (время по серверным часам + запас, убийства и крышки в секунду, волна, босс, хеш контента) и записывает флаги. Повторный `finish` возвращает уже начисленную награду. Новый `start` закрывает незавершённый забег с флагом `abandoned` (или `expired` старше часа). Покупка улучшения требует `expected_version`; при несовпадении — 409, клиент перечитывает профиль.

**Локации** выбираются в убежище: видны открытые и следующая закрытая (с подсказкой, чей босс её откроет), остальные — строкой «Дальше по карте ещё N мест»; их достижения тоже ждут, пока место не откроется. Прицельное оружие стреляет в мини-босса или босса, если он ближе `balance.run.eliteFocusRange`, иначе в ближайшего врага. Лекари лечат только обычных врагов. Сервер хранит убитых боссов в профиле (`bosses_killed`), отдаёт `unlocked_locations`, на `runs/start` в закрытую локацию отвечает 403 `locked`, а в `finish` умножает заработанную награду (без подобранных крышек) на `rewardMultiplier` локации; формула и общие тест-векторы одинаковы на клиенте и сервере.

**Эволюция оружия:** когда оружие достигло 8-го уровня, а парный перк взят хотя бы на 1-й уровень, на повышении уровня первой карточкой (золотая рамка, «ЭВОЛЮЦИЯ») предлагается улучшенная версия; сундук выдаёт готовую эволюцию в первую очередь. Эволюция заменяет базовое оружие; после выбора на паузе показывается экран эволюции (`EvolutionScene`): старая иконка заряжается и превращается в новую, рядом старый и новый снаряд, «сила ×N» (урон в секунду против 8-го уровня базы) и все изменившиеся числа. У каждой эволюции свой снаряд (`projectiles/<id>`, рисует `tools/assets/art_evolved.py`), у аур и молний — свой цвет (`color` в JSON). У каждого базового оружия два пути: они задаются в его JSON списком (`"evolutions": [{"passive": "...", "into": "..."}, ...]`). Если готовы оба, на повышении выходят две карточки эволюции — игрок выбирает путь, у эволюции один уровень и `"evolved": true`; она не выпадает как новое оружие. `make content-check` проверяет, что перк и цель существуют и у каждой эволюции ровно один источник.

**Карточки уровня** показывают, что именно изменится (`урон 6>8`), и значок пары для эволюции. Мест для оружия и перков — `maxWeapons` и `maxPassives`: в начале по 3 (статы `weaponSlots`, `passiveSlots`), оружию до 5, перкам до 6 докупается за изумруды (улучшения с `"currency": "emeralds"`); для тяжёлого оружия — `maxHeavyWeapons` (2), в начале 0, слоты покупаются за изумруды («Лафет»); одна из трёх карточек всегда оружие, пока есть что предложить; снизу видно, что уже взято. `R` или кнопка перебрасывает карточки (один раз за забег, больше — «Стол планирования»).

**Карта:** локация делится на биомы (`decor.biomes`, область `biomeChunks` × `biomeChunks` кусков), в части кусков вместо случайного декора стоит постройка из `content/structures/`. Лужи и трещины из `decor.hazards` ранят (мимо брони) или замедляют; `radResist` уменьшает и то и другое. Новое место или постройка добавляются только JSON; у места нужны кадры `landmarks/<id>` и `landmarks/<id>_used`.

**Выбор у мест** (`choices` в JSON места, сейчас у генератора и тайника). Когда герой впервые входит в круг, игра встаёт на паузу и показывает карточки (`LandmarkScene`): «Осторожно» (бесплатно, без боя, обычное удержание и награда), «Рискнуть» (засада сразу после выбора, затем удержание и больше наград плюс гарантированный сундук), «Выкупить» (крышки забега, награда сразу). На карточке заранее видны цена, угроза, время удержания и диапазон награды; без нужных крышек «Выкупить» серая и объясняет почему. «Уйти» (или Esc) оставляет место нетронутым: окно снова откроется, когда герой выйдет из круга и вернётся. Выбор фиксируется для места до конца забега (`WorldDecor` помнит его и после выгрузки куска), цена списывается и засада начинается один раз. Награда приходит только после удержания; уход из круга засаду не отменяет. Автопилот сразу берёт «Осторожно». Числа (`caps`, `holdMs`, `rolls`, `guaranteed`, `ambush`) — в JSON; `make content-check` требует бесплатную «Осторожно» без засады, засаду у «Рискнуть» сразу после выбора и платную «Выкупить» без удержания. Места без `choices` работают как раньше.

**Вход** — по ключу аккаунта: «Новая игра» создаёт аккаунт, ключ показан в «Настройках» убежища и открывает тот же аккаунт на другом устройстве (`POST /auth/key`). Ключ — 100 случайных бит, выводится из `JWT_SECRET` и id аккаунта, в таблице `recovery_keys` только хеш. После смены `JWT_SECRET` старый ключ работает, пока игрок не откроет новый. Почта и Telegram остались дополнительными способами. Аккаунт, чей ключ показали, не удаляется как гостевой.

**Скорость игры** — `balance.speeds`: на локации, где босс побеждён на ×1, открывается ×1,5, после победы на ×1,5 — ×2. Выбирается в убежище под списком локаций; сервер проверяет, что скорость открыта, и сверяет игровое время забега с настенным с учётом скорости. Достижения за победы на скорости — условие `victory` (локации × герои), к прочим можно добавить `minSpeed`.

**Герои** — `content/heroes/`: Скиталец (открыт), Искра (5 забегов), Молот (победа над Королём свалки), Ласка (9:15 в Мёртвом городе), Плесень (8 достижений). Условие в `unlock` проверяет сервер при старте забега (403 `locked`); сильные и слабые стороны на карточке считаются из разницы `baseStats` со Скитальцем. Спрайты 24×28 (ходьба 6 кадров, покой 4) и картинка убежища рисуются в `tools/assets/art_heroes.py`.

**Улучшения** разбиты на подвкладки (выживание, бой, добыча, слоты, особое); большинство имеет 8–10 уровней. «Полигон» (`headStart`) даёт повышения уровня в начале забега, «Аптечный шкаф» (`buffDuration`) продлевает усиления, «Набор отмычек» (`landmarkSpeed`) ускоряет места с наградой.

**Итог забега** (`ResultScene`, тексты — чистые функции `client/src/systems/runReport.ts`). Урон считается в `RunScene.damageMob` по оружию-источнику: снаряд, зона и взрыв помнят оружие, которое их выпустило; в счёт идёт только реально снятое здоровье (после лимита урона по элите и боссу, без перебора сверх остатка). Эти числа только показываются и на сервер не уходят. Цель «ДАЛЬШЕ» строится по профилю из ответа `finish` в таком порядке: следующая локация (её открывает босс предыдущей), герой или предмет, который откроется по прогрессу, покупка, на которую уже хватает, победа над боссом на большей открытой скорости. Рекорды времени и убийств по локации хранит сервер (`profile.data.records`) по принятым им числам; `finish` возвращает их в `record` вместе с прежними. Повторная отправка отдаёт те же числа, автопилот рекордов не ставит.

**Достижения** лежат в `content/achievements/`: `metric` считает сервер, `account` сервер выдаёт сам при входе (привязка почты, Telegram, вход по ключу — `profile.data.account_events`), `reported` замечает клиент (`systems/achievements.ts`), а сервер проверяет только `minSeconds`, `boss`, `autopilot`, `location` (достижение только на этой локации) и `minBoosts` (забег взял столько усилений, сервер знает это сам). Вкладка открывается с первым достижением; новое достижение выезжает баннером на итоговом экране, а изумруды при «Забрать» (или «Забрать всё») летят в счётчик; скрытые (`hidden`) не показываются, пока не получены.

Изумруды за достижение забирают кнопкой на вкладке (`POST /achievements/{id}/claim`, неполученные — в `achievements_unclaimed`).

**Экран:** в высоком окне игра 270×460–600, в широком 480×270 (`client/src/ui/layout.ts`); поворот телефона перестраивает интерфейс на лету. **Карточки уровня** выбираются случайно через `balance.run.levelUpTimeoutMs` (полоса сверху). **Мелодии** убежища и забега выбираются в настройках (`TUNES` в `assets.ts`).

**Открытие по ходу игры.** Вначале доступны только «Вылазка» и «Настройки»; остальные вкладки на рейке видны с замком: «Улучшения» — после первой вылазки, «Герои» — после второй, «Задания» — после третьей, «За изумруды» — с первым изумрудом, «Достижения» — с первым достижением (`client/src/ui/progression.ts`). Выбор скорости и автопилот скрыты, пока их нечем включить. Оружие и перки тоже открываются по пути (`unlock` с типом `runs`, `milestone`, `bossKilled`, `achievements`, как у героев): сначала только пистолет и обрез, затем мина (1 забег), бутылка (2), дрон (3), разрядник (3:50 у убежища), огнемёт (5), пила (6:10), радиополе (8), ракетная труба (босс убежища), лазер (3:50 в Мёртвом городе); перки «Счастливая крышка», «Конденсатор», «Шипованный жилет», «Вёрткость». Что доступно в забеге, считает сервер (`open_items` в профиле). Когда открылось новое, убежище показывает окно «Открыто новое!», а новая вкладка светится с меткой NEW, пока в неё не заглянут (что уже показано, помнит браузер).

**Стрелка к сундуку:** сундук, оставшийся за краем экрана (от босса или мини-босса), отмечается пульсирующей золотой стрелкой.

**Автопилот** (улучшение `autopilot`, 75 изумрудов) включается галочкой на вкладке «Вылазка» или клавишей `I`: убегает от ближних врагов и пуль, идёт к ближайшей добыче, сам берёт карточки и закрывает сундук. Вкладка должна быть видимой. Обычные достижения с ним не засчитываются.

**Изумруды** начисляет только сервер в конце забега, даже проигранного: за мини-боссов и боссов (`emeralds` локации, не больше, чем могло появиться к этому времени), за первую победу над боссом и за рубежи времени (`balance.reward.emeraldMilestones`, один раз на локацию). Баланс, открытые предметы и рубежи лежат в `profile.data`. `POST /unlocks/{id}/buy` открывает оружие или перк с `"unlock": {"type": "emeralds", "emeralds": N}`; он появляется среди карточек. Формула `emeraldReward` общая с сервером (`testdata/economy_vectors.json`). Везде, где цена или награда в изумрудах, после числа стоит значок изумруда.

**Усиления на один забег** (`content/boosts/`, раздел «На забег» вкладки «За изумруды»): стимулятор, бронежилет, запасное сердце, мешок для крышек, шпаргалка, кроличья лапка, реактивные ботинки. `POST /boosts/{id}/buy` списывает изумруды и кладёт усиление в рюкзак (`profile.data.boosts`, каждое не больше одного раза); `runs/start` забирает весь рюкзак в забег (`runs.boosts`, миграция 0007) и отдаёт список в ответе, даже если из забега потом выйти. `effects` добавляются к статам как улучшения убежища, `rewardBonus` сервер умножает на множитель награды локации. На экране «Вылазка» видно, что взято с собой.

**Мини-боссы** втрое крупнее рядовых врагов: красное кольцо, полоса здоровья над головой, красная стрелка у края экрана, рёв при появлении, фазы атак. За секунду мини-босс теряет не больше `eliteMaxLossPerSecond`, босс — `bossMaxLossPerSecond` здоровья, поэтому бой не кончается мгновенно. Босс крупнее в `scale` раз. **Подсказки:** наведите мышь на слот или значок бонуса в забеге.

**Сундук** (после мини-босса) не даёт выбора: открывается с анимацией и звуком, барабаны по очереди останавливаются на случайных предметах (первое касание пропускает анимацию, второе закрывает). Он сразу улучшает 1–3 предмета (сначала готовую эволюцию, затем уже взятые, по возможности разные; удача повышает число) и даёт крышки. **Ландшафт** генерируется кусками 256×256 из seed забега: асфальт, воронки, светящиеся лужи, дюны, остовы машин, бочки, деревья, кости, шины. **Ящики** на карте разбиваются выстрелом или касанием и дают бонус. Волны, время появления мини-боссов и босса, декор и содержимое ящиков задаются в `content/locations/`.

Поведения работают через маленькие интерфейсы (`client/src/behaviors/types.ts`), а не через объекты Phaser, поэтому у каждого есть юнит-тест (`behaviors.test.ts`). Новое поведение: класс + Zod-схема параметров + регистрация в `behaviors/registry.ts` + тест; поля уровня оружия, которые ему нужны, перечисляются в `requiredLevelFields` и проверяются `make content-check`.

## Графика и звук

Все спрайты, звуки и музыка — собственные (CC0) и собираются скриптом `tools/assets/build_assets.py` (`make assets`) из исходников в репозитории: пиксельные карты в `tools/assets/art.py`, новое оружие, места и постройки в `art_extra.py`, пять поздних локаций (враги, боссы, декор, земля), новая крышка и иконки усилений в `art_lands.py`, синтез звука и трекер музыки в `tools/assets/audio.py`. Результат лежит в `client/public/assets/` и коммитится, так что для игры и CI скрипт не нужен; повторная сборка даёт те же байты. Лицензии — в `client/public/assets/CREDITS.md`.

- **Атлас** `atlas/sprites.png` + JSON Hash. Кадр `<ключ>` — статичный кадр спрайта из контента (`heroes/wanderer`), кадры `<ключ>/<анимация>_<n>` превращаются в анимации автоматически (`walk`, `death`, `idle`, `burst`).
- **Новый враг со спрайтом:** нарисуйте карту в `art.py` (16×16, символы палитры), добавьте его в `sprite_frames()` (для ходячих — `humanoid(...)`, кадры смерти генерируются), выполните `make assets` и `make content-check`.
- **Звуки:** оружие ссылается на звук выстрела (`fireSound: "sfx/…"`), локация — на музыку (`music: "music/…"`), перки — на иконку (`sprite`). Одновременно звучит не больше трёх экземпляров одного звука.
- **Интерфейс:** стиль ЭЛТ-терминала, шрифт Press Start 2P с кириллицей (OFL, npm-пакет `@fontsource/press-start-2p` — единственная новая зависимость, нужна, чтобы шрифт с кириллицей собирался Vite вместе с клиентом и работал офлайн и в Capacitor). Размеры шрифта кратны 8 px, чтобы пиксели оставались чёткими.
- **Настройки** в убежище: музыка, звуки и ЭЛТ-эффект (сканлайны и виньетка поверх экрана, по умолчанию выключен); хранятся в `localStorage`.

## Android

Android-сборка — та же веб-сборка в Capacitor 8 (`client/android`, `client/capacitor.config.ts`). Новые зависимости: `@capacitor/core`, `@capacitor/android`, `@capacitor/cli` (сама обёртка), `@capacitor/preferences` (токены на устройстве), `@capacitor/app` (кнопка «назад», сворачивание, ссылки входа), `@capacitor/app-launcher` (открыть бота в приложении Telegram).

- **Нужно:** JDK 21 (`JAVA_HOME`) и Android SDK с платформой 36 (`ANDROID_HOME`), лицензию SDK принимает пользователь (`sdkmanager --licenses`).
- **Телефон для проверки:** `make dev`, телефон по USB с отладкой, затем `make android-debug` — сборка с API `http://localhost:8000`, `adb reverse` пробрасывает порт на компьютер, APK ставится и запускается. HTTP разрешён только в debug и только для localhost.
- **Релиз одной командой:** `ANDROID_PUBLIC_URL=https://<домен> WASTELAND_KEYSTORE=<путь> WASTELAND_KEYSTORE_PASSWORD=… WASTELAND_KEY_ALIAS=… WASTELAND_KEY_PASSWORD=… make android-aab` → `client/android/app/build/outputs/bundle/release/app-release.aab`. Ключ и пароли — вне репозитория; без них сборка падает с подсказкой. Ключ создаётся так: `keytool -genkeypair -v -keystore upload.jks -alias upload -keyalg RSA -keysize 4096 -validity 10000`. Версия — `WASTELAND_VERSION_CODE` и `WASTELAND_VERSION_NAME`.
- **Вход:** токены хранятся в `@capacitor/preferences` (в браузере — `localStorage`, общий интерфейс `TokenStore`). Ссылка из письма `https://<домен>/login?token=…` открывает приложение (App Links, хост берётся из `ANDROID_PUBLIC_URL`); сервер отдаёт `/.well-known/assetlinks.json` по `ANDROID_PACKAGE` и `ANDROID_CERT_FINGERPRINTS` (SHA-256 ключа подписи; при Play App Signing — ключа из консоли Play). Кнопка Telegram открывает бота в приложении Telegram. Сервер должен разрешать CORS для `https://localhost` — origin WebView.
- **Поведение:** вертикальная или альбомная ориентация (как держат телефон), полноэкранный режим (панели появляются по свайпу), отступы под вырез камеры через `env(safe-area-inset-*)`. «Назад» в забеге — пауза, в убежище и на экране входа — выход с подтверждением. Сворачивание ставит забег на паузу и выключает звук (в браузере уход со вкладки тоже ставит паузу).
- Иконка и заставка генерируются `make assets` из спрайта героя.

## Деплой

Инструкция с нуля и проверка — [docs/DEPLOY.md](docs/DEPLOY.md); конфиги nginx, systemd, PgBouncer, бэкап и выкладка — в `deploy/`. Служебные команды (из `server/`): `python -m app.services.check_config` (проверка боевых настроек), `… cleanup` (удаление гостей без активности 90 дней и просроченных входов; systemd timer), `… telegram_webhook set|info`.

Публичные страницы `/privacy`, `/delete-account`, `/help` и `/changelog` собираются вместе с клиентом. «Помощь» берёт героев, оружие с эволюциями, перки, усиления и локации прямо из `content/` (иконки — из атласа), «Что нового» — из `client/src/changelog.ts`. Каждый коммит поднимает версию в `client/package.json` (третья цифра, большие изменения — вторая); она же видна в «Настройках». В журнал попадает только то, что важно игроку, поэтому номера могут идти с пропусками, а скрытые достижения не называются — только «новые скрытые достижения» (проверяет тест). Ссылки на обе страницы — во вкладке «Настройки»; контакты задаются при сборке через `VITE_CONTACT_EMAIL`, `VITE_OPERATOR`, `VITE_BACKUP_DAYS`. Страница удаления входит отдельно от игры и не затрагивает гостевую сессию. Локально: `make dev`, затем `http://localhost:5173/delete-account`.

## Проверка вручную

1. Запустите `make dev`, откройте клиент и нажмите «Новая игра» (или войдите по ключу, почте, Telegram). Откроется убежище: крышки, лучшее время, число забегов и список улучшений с ценами. На вкладке «Вылазка» нажмите «Отправиться на вылазку» (или пробел). Герой двигается через WASD/стрелки, на таче — плавающим джойстиком под пальцем. Мышью: клик — герой идёт в эту точку, удержание — идёт за курсором. Оружие автоматически стреляет в ближайшего врага.
2. Соберите кристаллы опыта, выберите улучшение кликом или клавишами 1–3. Нажмите P или Esc для паузы, ещё раз — чтобы продолжить. В меню паузы есть громкость музыки и звуков и «Вернуться в убежище» (второе нажатие подтверждает): заработанное засчитывается. Внизу видны слоты: слева оружие, справа перки. После смерти откроется итоговый экран: сначала оценка награды, затем награда от сервера и новый баланс. Справа (на телефоне — ниже) видно, какие три оружия нанесли больше всего урона и их доли (остальное и шипы — «Другое»), сборку с уровнями, взятую эволюцию по имени и эволюцию, до которой не хватило немногого. После ответа сервера появляются личные рекорды локации и одна цель «ДАЛЬШЕ» в убежище. «В убежище» возвращает в хаб. Если сервер недоступен, появится «Повторить»; после запуска сервера повтор засчитает тот же забег.
3. В убежище купите улучшение (первый забег даёт около 10–15 крышек, «Бронепластины» стоят 30). Баланс уменьшится на цену, уровень и следующая цена обновятся. В следующем забеге «Полевая подготовка» увеличивает максимум здоровья на HUD. Чтобы проверить 409, в другой вкладке купите улучшение и затем нажмите «Купить» в старой: появится «Профиль изменился», профиль перечитается.
4. Прогресс на другом устройстве: в убежище гостя привяжите почту, откройте игру в другом браузере, войдите по коду из лога сервера — крышки и улучшения те же.
5. Поддельная сводка: возьмите `access_token` из `localStorage['wasteland.auth.v1']`, вызовите `POST /api/v1/runs/start`, затем сразу `POST /api/v1/runs/{run_id}/finish` с `{"content_hash": "...", "duration_seconds": 60, "kills_by_type": {"ghoul": 10000}, "wave_reached": 3, "boss_killed": true, "picked_caps": 10000}`: в ответе урезанная награда и флаги `duration_clamped`, `kills_clamped`, `caps_clamped` и т. д.
6. Откройте `/api/v1/health`: при доступной БД ответ `{"status":"ok","database":"ok"}`. Если БД недоступна, сервер вернёт HTTP 503 в формате `{ "code": ..., "message": ... }`.
7. Локации: в убежище в «Куда идём» открыта только «Пустошь у убежища», остальные серые с подсказкой. После победы над Королём свалки открывается «Мёртвый город» (стаи псов, радиомыши, лекари с зелёной волной лечения, штурмовой мех на 3:30, Железный мэр в 10:00), после мэра — «Ядовитые топи» (слизь делится при смерти, черви становятся полупрозрачными под землёй и выныривают с ударной волной, жабы плюются, королева слизи и великий червь, Мать топей). У каждой локации своя земля, декор и музыка; награда за город ×1,5, за топи ×2. Дальше по цепочке — «Военная база» (рядовые-стрелки, дроны, ползучие мины, мехи, Стальной генерал), «Чёрный лес» (волки, клещи, грибы-споровики, медведь, Хозяин леса), «Подземелье» (крысы, пауки, слепые копатели, паучиха-матка, Крысиный король), «Ледяной перевал» (полярные волки, ледяные жуки, морозные стрелки, ледяной голем, Королева стужи) и «Великая пустыня» (стервятники, песчаные черви, кочевники, скорпион-царь, Песчаный левиафан). Плевки жаб и паучихи теперь розовые, а не зелёные, как опыт. Для быстрой проверки в dev выберите локацию и добавьте `?wave=3` (3:05) или `?wave=8` (босс).
8. Контент: на 3:30 появляется предупреждение и громила с полосой здоровья внизу; после убийства подберите сундук — откроется экран с улучшениями. Ящики на карте разбиваются касанием или выстрелом, из них падают аптечки, магниты, гранаты и крышки (над героем всплывает подпись). В 10:00 приходит Король свалки под отдельную музыку; при 66 % и 33 % здоровья он меняет тактику и зовёт подмогу, после убийства — «ПОБЕДА!» и бонус к награде. Для быстрой проверки в dev используйте `?wave=8` (10:00).
9. Графика и звук: в убежище играет музыка «Убежище», интерфейс зелёный. В забеге герой и враги анимированы и разворачиваются по направлению движения, у врагов есть анимация смерти, у попаданий — искры, кристаллы мерцают. Звучат выстрелы (у обреза свой звук), попадания, подбор опыта, новый уровень и урон. При смерти герой падает, через секунду открываются итоги со звуком награды. Снимите галочки «Музыка» и «Звуки», включите «ЭЛТ-эффект» — каждая настройка выключается сразу и сохраняется после перезагрузки.
10. Карта и бонусы: идите по жёлтой стрелке у края экрана к месту с кругом; стойте в круге до конца шкалы — выпадет награда, у тайника и генератора придёт засада, у автомата спишутся крышки забега. Встаньте в зелёную лужу — здоровье убывает. Подберите стимулятор: слева вверху иконка с таймером. На уровне нажмите `R` — карточки сменятся. С «Дефибриллятором» первая смерть за забег возвращает половину здоровья.
11. Эволюция: прокачайте оружие до 8-го уровня и возьмите парный перк (см. таблицу выше) — на следующем повышении уровня первой будет золотая карточка «ЭВОЛЮЦИЯ»; после выбора появляется экран эволюции с анимацией и списком изменений, затем иконка, снаряд и поведение оружия меняются (у дрона — 7 дронов постоянно на орбите). Если в этот момент открыть сундук, эволюция придёт из него.
12. Изумруды: убейте мини-босса (3:30) или продержитесь 3:50; итоговый экран покажет изумруды. В убежище на вкладке «Оружие» откройте роторный пулемёт (18) — с 8 уровня он встречается среди карточек и занимает жёлтый слот, если во «Слотах» куплен «Лафет». Наведите мышь на слоты внизу — появятся подсказки. Вкладка «Изумруды» перечисляет, за что их дают.
13. Ключ: в «Настройках» нажмите «Показать», скопируйте ключ, откройте игру в другом браузере и введите его — тот же баланс и забеги. Неверный ключ даёт понятную ошибку; после «Сменить ключ» старый не подходит.
14. Достижения: нажмите на героя 10 раз подряд — появится баннер, после забега откроется вкладка «Достижения». Автопилот: купите его, поставьте галочку и начните вылазку, ничего не нажимая. Награду заберите кнопкой на вкладке. Откройте игру на телефоне вертикально, поверните его в забеге: картинка перестроится, пауза сохранится.
15. Итог забега: сыграйте пару минут и умрите. Справа (на телефоне — под временем) видны три оружия с долями урона, сборка и «ДАЛЬШЕ: …»; второй забег на той же локации покажет «Новый рекорд…» или прежний рекорд. Поверните телефон на итоговом экране — числа не меняются, награда не начисляется повторно.
16. Выбор у мест: найдите генератор или тайник (жёлтая стрелка у края экрана) и войдите в круг. Игра встанет на паузу и покажет три карточки. «Уйти» — место не тронуто, выйдите из круга и вернитесь, окно откроется снова. «Выкупить» без крышек серая. «Рискнуть» — сразу засада, затем удержание и сундук; после выбора окно больше не появляется.
15. Герои: на вкладке «Герои» закрытые показаны силуэтом с условием; после 5 забегов откроется Искра. Выберите её и начните вылазку: другой спрайт, здоровье и оружие.
16. На экране убежища можно привязать почту/Telegram к гостю и удалить аккаунт вместе с данными. Гостю после третьего забега показывается предложение привязать вход. Выполните `make test` и `make content-check`.

В dev-режиме `?autostart` сразу начинает забег из убежища, `?seed=42` заменяет серверный seed, `?wave=1` запускает вторую волну (нумерация с нуля). Во второй волне появляются два типа врагов. На повышении уровня обрез появляется среди карточек как новое оружие. HUD показывает FPS, число врагов и снарядов. Контрольный замер в headless Chromium после перехода на анимированные спрайты (этап 5): 300 врагов и 500 снарядов, 120 кадров за 2 секунды.
