# Открытые вопросы

- Куда отправить репозиторий игры? Локальный Git и ветка `stage-0` созданы в этой папке. Для PR нужен отдельный remote игры; родительский `origin` относится к dotfiles и использовать его нельзя.
- В окружении Python 3.14 и нет глобального `uv`. Этап 0 проверен временной установкой `uv` и PostgreSQL 17. CI использует Python 3.12; проверка именно на 3.12 остаётся за первым запуском CI.
